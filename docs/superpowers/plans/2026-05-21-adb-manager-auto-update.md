# ADB Manager Auto Update Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add GitHub Release based in-app update checks, user-confirmed downloads, and updater release metadata for ADB Manager.

**Architecture:** Use Tauri 2 updater with a committed public key and a private signing key stored outside git. The frontend owns user-facing update prompts and manual Settings checks; release tooling owns `latest.json` generation from signed artifacts.

**Tech Stack:** Tauri 2, React, TypeScript, Mantine, GitHub Releases, Tauri updater static JSON.

---

### Task 1: Generate Updater Signing Key

**Files:**
- External secret: `~/.tauri/adb-manager-updater.key`
- External public key source: generated by Tauri signer
- Modify later: `src-tauri/tauri.conf.json`

- [ ] **Step 1: Confirm signer command syntax**

Run:

```bash
npm run tauri signer generate -- --help
```

Expected: CLI shows the `-w` or `--write-keys` option.

- [ ] **Step 2: Generate the private key outside the repository**

Run:

```bash
mkdir -p ~/.tauri
npm run tauri signer generate -- -w ~/.tauri/adb-manager-updater.key
```

Expected: private key is written under `~/.tauri`, and the command prints a public key.

- [ ] **Step 3: Verify no private key entered git**

Run:

```bash
git status --short
find . -maxdepth 3 -name '*updater*.key' -o -name '*.key'
```

Expected: no updater private key appears inside the repository.

- [ ] **Step 2: Configure updater artifacts and endpoint**

Update `src-tauri/tauri.conf.json` so it includes:

```json

    "createUpdaterArtifacts": true
  },
  "plugins": {

      "endpoints": [
        "https://github.com/burpeepoo/adb-devices/releases/latest/download/latest.json"

      "windows": {
        "installMode": "passive"

    }
  }
}
```

Expected: JSON remains valid and existing bundle settings are preserved.

- [ ] **Step 1: Create updater hook**

Create `useAppUpdater` with these responsibilities:

```ts
type UpdateStatus = "idle" | "checking" | "available" | "not-available" | "downloading" | "ready" | "error";
```

The hook calls `check()`, stores the returned update, downloads through `downloadAndInstall()`, tracks byte progress, and calls `relaunch()` after installation.
