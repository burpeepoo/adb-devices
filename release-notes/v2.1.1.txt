en-US:
ADB Manager 2.1.1 includes the Display Color calibration readout improvements from 2.1.0 and the default-window layout hotfix from 2.1.1.

- Display Color temperature and color-wheel controls now show the operator-friendly `#RRGGBB · x,y` value in the main UI, while preserving the signed Settings integer as "Firmware Raw Value" for firmware and supplier handoff. The underlying apply and export parameters are unchanged.
- Device Console tool buttons in the device utility groups now shrink within their cards instead of overlapping neighboring buttons or sections.

zh-CN:
ADB Manager 2.1.1 包含 2.1.0 的 Display Color 调色读数优化，以及 2.1.1 的默认窗口布局修复。

- Display Color 色温和色环控件现在在主界面显示更容易理解的 `#RRGGBB · x,y`，同时把 signed Settings 整数保留为“固件原始值”，方便继续交给固件和供应商。底层应用到设备与导出的参数不变。
- 设备控制台工具组里的按钮现在会在卡片内自适应收缩，不再和相邻按钮或区块重叠。
