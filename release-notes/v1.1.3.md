## English

- Added a red update indicator on the Settings button when a new version is available.
- Added an automatic update check setting, enabled by default.
- When automatic checks are enabled, ADB Manager checks silently at launch and every 6 hours while open.
- Silent checks no longer open the update dialog immediately; they surface available updates through the Settings indicator.

## 中文

- 当发现新版本时，设置按钮右上角会显示红色提示点。
- 新增“自动检查更新”开关，默认开启。
- 开启后，ADB Manager 会在启动时静默检查一次，并在应用打开期间每 6 小时静默检查一次。
- 静默检查发现新版本时，不再立即弹出更新窗口，而是通过设置按钮上的红点提示。
