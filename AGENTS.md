# Project Instructions

- Before any UI, UX, styling, layout, visual validation, design-system, or frontend component work in this project, always read `DESIGN.md` from the project root first.
- Follow the tokens, utilities, component anatomy, spacing, typography, and states described in `DESIGN.md`.
- The design system stylesheet lives at `src/styles/system.css` and should be wired into the app only once through the global CSS entry.
- If `html/preview.html` exists in a future revision, read it as a visual reference before changing UI.
- For UI smoke validation, use the Tauri desktop app flow instead of a browser-only Chrome preview, because this project depends on the bundled ADB environment.
